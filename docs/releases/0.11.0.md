# Jarvis 0.11.0

## Release summary

Jarvis 0.11.0 makes the CLI local-first and independent of AI Stack for ordinary repository work. Bare tasks and the no-argument interactive shell use the standalone agent loop, which sends model requests directly to the configured OpenAI-compatible inference endpoint.

## Highlights

- Route bare tasks to the local agent by default.
- Use `INFERENCE_BASE_URL` and `INFERENCE_API_KEY` to connect to the dedicated `jarvis-inference` gateway.
- Make the streaming command call the inference API directly instead of importing AI Stack internals.
- Prefer direct gateway diagnostics in `jarvis model-doctor` when the inference endpoint is configured.
- Keep durable remote Runs and shared platform features available through explicit `jarvis run` and `jarvis cloud` commands.
- Document the independent boundaries between Jarvis, Jarvis Core, AI Stack and jarvis-inference.

## Upgrade notes

Configure the direct inference endpoint before using the default local workflow:

```bash
export INFERENCE_BASE_URL=http://<inference-host>:8080/v1
export INFERENCE_API_KEY=<inference-secret>
export JARVIS_MODEL=qwen3:1.7b
jarvis model-doctor
```

The legacy AI Stack integration remains available through explicit remote commands. A configured `AI_STACK_BASE_URL` alone is no longer enough to run a bare local task.
